Onlinja is a digital, modern board game adaptation, inspired by [Linja](https://steffen-spiele.com/products/linja), made by [Steffen Mühlhäuser](https://steffen-spiele.com). It was built to embrace minimalism and provide an enjoyable experience for anyone on-the-go.

And it all started just because I saw how good of a job [Chess.com](https://www.chess.com/) did with their online chess adaptation, and I wanted to do a similar thing with Linja.

Developing Onlinja I went a step further to learn new technologies - React Native and game bot development, paired with:
- **Typescript** for type safety and better code quality.
- **Expo** for cross-platform mobile development.
- **Docker** for production deployment.
- **Agentic development** for alignment with today's standards.

The game follows a clean architecture built from ground up, where many things are separated modules for easy prototyping. Game design was made to be accessible, with an interactive tutorial and a simple interface.

Game allows everyone to match against a bot, or play against friends on one screen, together!

For the first time I also tried out using agents properly, designing harnesses through skills to drive the development. Agents I was using weren't perfect, especially with a project that requires heavy work with graphics and UI, but they helped figuring out React Native.

Onlinja is one of my best projects to date just by how fun it is to play, and how far I pushed myself to create a professional project. And, of course, it wouldn't be a DoMax project without a live demo, so you can try it out at [Onlinja's official page](https://onlinja.domax.lt)!

And if you want to learn more about how Onlinja was made, you can read about it [here](/blog/onlinja).
